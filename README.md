# roblox-ui-asset-organizer

A Roblox Studio plugin that automatically tags and organizes UI elements by type and hierarchy depth.

## Stack

Primary language: **Luau**

## Project structure

- `src/Plugin.lua` — Streamlines UI asset management by applying consistent tags and sorting UI elements in the Explorer.
- `plugin.json` — plugin metadata

## Usage

Review the source files and install any dependencies referenced by the project before running it.
